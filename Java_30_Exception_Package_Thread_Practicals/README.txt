JAVA EXCEPTION, PACKAGE AND THREAD PRACTICALS

Contents
01_Exceptions: 10 exception handling programs.
02_Packages: 10 package/import exercises. Each package exercise has its own folder and README with compile/run commands.
03_Threads: 10 multithreading programs.

Requirements: Install a JDK and ensure javac/java are available in Command Prompt.

For a normal standalone file, open its folder and run:
  javac FileName.java
  java ClassName

Important: Package exercises must be compiled from their own exercise folder using the commands in that folder's README. Do not compile package exercises from an unrelated working directory.

Note: Thread scheduling and the unsynchronized counter's incorrect result are nondeterministic; the unsynchronized example may occasionally print the expected value by chance.
